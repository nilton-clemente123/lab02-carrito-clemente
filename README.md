##  Preguntas

### ¿Por qué `nombre` y `precio` son `val`, pero `cantidad` es `var`?

Nombre y precio son val por que se supone que estas variables seran inmutables o no cambiaran con el pasar del tiempo, cantidad es var por que dicho valor es mutable 

### ¿Qué pasaría si intentas cambiar el precio después de crear el producto?

Simplemente no seria posible ya que el precio al ser una variable inmutable no puede cambiar su valor
